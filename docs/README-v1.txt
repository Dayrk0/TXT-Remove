一、项目简介
---------------
本工具用于从 TXT 小说文件中自动查找并删除夹杂的广告语句（如网站链接、HTML 标签等）。
提供图形界面，支持自定义检索词（AND/OR 组合），并可手动复核检索结果后再执行删除。
最终版本基于 PyQt5 实现，界面美观，功能实用。

五、运行方式
---------------
1. 确保已安装 PyQt5。
2. 双击 小说广告清理_pyqt.py 或在命令行执行：
     python 小说广告清理_pyqt.py
3. 程序窗口：
   - 选择小说 TXT 文件（通常十几 MB）
   - 输入检索词，支持 AND / OR 组合（例如：棉花糖 AND 小说 OR 求书小说网）
   - 点击“检索”，程序将匹配到的广告句写入桌面上的“检索结果.txt”
   - 打开“检索结果.txt”，手动删除不想清理的条目（按序号标识），保存文件
   - 选择输出目录（点击“浏览”按钮指定）
   - 点击“删除广告”，程序将基于编辑后的检索结果执行删除，生成“原文件名去广告.txt”
4. 底部有提示文字：“检索后请先打开桌面上的‘检索结果.txt’，手动删除您不想清理的条目并保存，再点击‘删除广告’。序号被删的句子将不会被删除。”

六、主要功能演变
---------------
1. 初始版本（Tkinter）
   - 基础文件选择、检索、删除
   - 输出“检索结果.txt”到桌面，删除功能可覆盖原文件或另存为 _clean.txt
   - 句子边界仅基于中英文句号、问号、感叹号和换行符

2. PyQt5 重写 + 手动编辑删除
   - 界面升级为 PyQt5，Fusion 风格
   - 支持用户手动修改“检索结果.txt”后，程序重读该文件，只删除文件中保留序号的句子
   - 移除覆盖原文件/备份功能，改为用户指定输出目录，生成“原文件名去广告.txt”

3. 句子边界优化
   - 原边界遗漏了 HTML 闭合标签（如 </a>、</strong>）和右括号 ]、) 等，
     导致广告标签与正文粘连，误删正文。
   - 在基础分隔符上增加了 </a>、</strong>、</span>、</div>、]、) 等，使用 re.IGNORECASE
   - 解决了大部分 HTML 广告混入正文的问题

4. 进一步优化（最终版）
   - 再次扩展句子边界：增加中文右双引号 ”、英文右双引号 "、各种全角右括号 ） 】 》 ｝、右单引号等
   - 界面布局更宽松，按钮和输入框尺寸加大，日志区增高
   - 增加“编辑分隔符”按钮，可打开模态对话框动态修改句子分割正则，支持恢复默认
   - 底部添加用户提示文字，说明手动编辑检索结果的流程

七、提示词文件说明
---------------
- prompt1：最初提出的完整 Tkinter 需求，包含大文件处理、检索表达式解析、句子删除逻辑等。
- prompt2：要求将 Tkinter 替换为 PyQt5，并实现“手动编辑检索结果.txt 后再删除”的功能；
           同时要求输出目录自定义（生成“原文件名去广告.txt”）。
- prompt3：针对检索结果中出现的误删问题，要求扩展句子边界，加入 HTML 闭合标签和右括号。
- prompt4：进一步优化边界（补充各种引号、括号），界面微调，增加可编辑分隔符的窗口，
           以及底部提示标签。

八、注意事项
---------------
- 如果小说编码特殊，程序会依次尝试 utf-8-sig、gbk、gb18030，若均失败会报错，请先将 TXT 另存为 UTF-8。
- 手动编辑“检索结果.txt”时，请保持每行的序号格式 [数字] ，不要修改序号本身；若删掉某行，该序号对应的句子就不会被删除。
- 分隔符编辑属于高级功能，请确保输入的是合法的正则表达式，否则程序会提示并拒绝保存。
