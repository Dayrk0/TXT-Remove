当前问题：
现有的句子边界只考虑了句号、问号、感叹号和换行符，导致 HTML 标签广告（如 <a ...>...</a>、<strong>...</strong>）以及方括号/圆括号广告与其后的正文被识别为一个句子，整句被误删。

例如下面这一句原文被整体识别为广告并删除，但后半截正文需要保留：
[110] <a href="http://www.mianhuatang.cc" target="_blank">棉花糖小说网WWW.Mianhuatang.CC</a>”苏灿让程可淑等一下，在水果摊的面前挑选了一些苹果……

错误的根源在于 </a> 没有被当作句子边界，导致标签后的正文被合并。

优化要求：
1. 扩展句子边界的定义，在原有 `[。！？!?\n]` 基础上，增加以下字符/字符串作为句子分隔符：
   - </a> （不区分大小写？示例中均为小写，可直接匹配小写，但最好不区分大小写，写法： (?i)</a> 或直接增加 </a> 即可，正则默认区分大小写，我们可将整个正则设置为不区分大小写，或显式写出 </a> 与 </A>，但为简单，要求匹配 </a> 和 </A>。由于广告标签在中文小说中几乎都是小写，可只加 </a> 和 </strong>，但为鲁棒，建议使用 `</[^>]+>` 匹配任意闭合标签，但这可能误伤正文中的 </ 符号，权衡后，我们就添加常见的 </a>、</strong>、</span>、</div>、</p> 等。实际出现最多的就是 </a> 和 </strong>，请添加这两个，再加上 </span> 和 </div> 备用。注意正则写法：在原有字符组后添加 |</a>|</strong>|</span>|</div> 
   - 方括号闭合符号：] （需在正则中转义为 \]）
   - 圆括号闭合符号：) （需转义为 \)）

   最终的正则字符串可写成：
   SENTENCE_BOUNDARY = re.compile(r'(?<=[。！？!?\n]|</a>|</strong>|</span>|</div>|\]|\))', re.IGNORECASE)
   注意：使用了 re.IGNORECASE 让标签匹配忽略大小写，但 [。！？!?\n] 是字符类不受影响。

2. 同时考虑开头的 <a ...>、<strong> 等是否也需要作为句子开始？不需要，因为分割只使用结束分隔符保留在句末的方式，我们只需要在闭合标签处断开，确保标签部分独立成句，之后的正文从下一个字符开始成为新句即可。

3. 修改后，需保证原有逻辑不变：分割后每个句子元素包含末尾分隔符，删除匹配的句子时直接丢弃该元素，其余拼接。
