# 开发记录

## 1.x：从 Tkinter 到 PyQt5

项目最初用于清理 TXT 小说中夹杂的广告句，完整的历史需求保存在 `docs/prompt1-初始需求.txt` 到 `docs/prompt4-进一步优化.txt`，原始项目记录在 `docs/README-v1.txt`。最初的 VibeCoding 对话记录：

<https://chat.deepseek.com/share/xbvp80p55r0sdas8we>

主要迭代：

1. **Tkinter 版本**：选择文件、关键词检索、结果写入桌面 `检索结果.txt`，删除后可覆盖原文件或另存为 `_clean.txt`。句子边界仅包含中英文句号、问号、感叹号和换行。
2. **PyQt5 重写 + 人工复核**：界面迁移到 PyQt5；检索结果按 `[序号] 句子` 输出，用户可以在记事本中删除不想清理的行，程序重读结果文件后只删除保留序号对应的句子。输出改为用户指定目录下的 `原文件名去广告.txt`，不再覆盖原文件。
3. **边界规则修正**：补充 `</a>`、`</strong>`、`</span>`、`</div>`、`]`、`)` 等右边界，解决 HTML 广告与正文粘连导致的误删。
4. **进一步优化**：补充中文右引号、全角右括号等边界；增加可编辑分隔符的模态对话框和恢复默认；界面尺寸、日志区和提示文字调整。

1.x 的程序文件为 `小说广告清理_pyqt.py`，Tkinter 版本为 `小说广告清理工具.py`。2.0 整理时分别改名为 `小说广告清理工具.py`（PyQt5 主程序）和 `legacy/小说广告清理工具_tkinter.py`。

## 2.0：重构目标

保留原有用途和可用功能，重点改进三件事：

- **TXT 处理**：编码、换行、句子切分和结果文件的边界情况。
- **界面与交互**：让“选文件 → 检索 → 复核 → 保存”更清楚，减少误操作。
- **可维护性**：把文本处理从界面中拆出，补充测试和项目文档。

明确不改变的约定：

- 原文件只读，清理结果另存。
- 检索结果仍以 `检索结果.txt` 为中心，仍支持人工删行复核。
- `AND` / `OR` 的语义、区分大小写的子串匹配保持不变。
- 输出仍为 `原文件名去广告.txt`。

```text
小说广告清理工具.py   界面、交互、主题、设置与对话框
```

`adclean_core.py` 只依赖标准库，因此编码、切句和结果文件逻辑可以脱离 Qt 单独测试。GUI 通过 `import adclean_core as core` 使用这些能力。

## 2.0 的关键改动

### 检索与复核

- 检索在 `QThread` 中执行，逐批报告进度，可取消；大文件不会阻塞窗口。
- 先读取并切句，再用解析后的查询逐句匹配；命中句写入桌面结果文件。
- 结果文件每行 `[序号] 句子`，序号对应本次切句的索引；删除时取“结果文件保留序号 ∩ 当前句子索引”。
- 即使 0 条命中也会重写结果文件，避免旧文件残留造成误判。
- 结果文件写入前把句内换行替换为空格，保证一行一条，避免记事本复核时出现空行。

### 句子切分

- 默认边界保留 1.x 的扩展规则：中英文句号/问号/感叹号、换行、HTML 闭合标签、常见右括号和右引号。
- 切句后用“文本片段 + 边界”成对还原，保证 `''.join(sentences) == 原文`。
- 仅由空白组成的片段合并到前一句，避免删除广告句后留下孤立换行；末尾空片段丢弃。
- 分隔符编辑对话框会检查正则是否合法、是否恰好包含一个捕获组、是否能匹配空串；合法后立即预览切分结果。

### 编码与换行

- 读取顺序：BOM → UTF-8 → GBK → GB18030 → Big5；UTF-16 仅在检测到 BOM 或明显 NUL 分布时尝试。
- 文本统一为 LF 处理，保存时按原文件的换行风格写回。
- 输出编码可选 UTF-8（带 BOM，默认）、UTF-8、跟随原文件、GB18030。
- **限制**：Big5 自动识别是尽力而为。GB18030 经常能把 Big5 字节解成“合法但错误”的字符，无法仅靠解码是否成功判断；UTF-16 无 BOM 时也不保证识别。遇到乱码请先另存为 UTF-8。

### 写入安全

- 保存前再次检查源文件大小和 `mtime_ns`；检索后源文件被修改则中止，要求重新检索。
- 输出文件名为 `原文件名去广告.txt`；若原名已含“去广告”，使用 `_clean` 后缀，避免覆盖源文件。
- 输出路径与源文件相同则拒绝写入。
- 先写同目录临时文件，再 `os.replace` 原子替换；失败不会留下半截文件。
- 保存前确认，目标已存在时单独询问覆盖。
- 保存成功后保留命中预览，但清空删除索引并禁用删除按钮，防止重复删除。

### 界面

- 2.0 使用浅色/深色两套 QSS、卡片式左侧操作区和右侧“命中预览 / 运行日志”双标签。
- 头部包含主题切换、使用说明和设置；底部显示本机处理提示和版本。
- 文件区显示大小、编码、字符数、句子数；输出目录默认跟随源文件。
- 查询框可编辑并保存最近 10 条历史；常用规则覆盖网址、公众号、求书、盗版站、HTML 闭合标签、下一页等场景。
- 检索结果显示前 200 条，关键词高亮；日志记录读取、切句、匹配、写入耗时。
- 分隔符对话框实时校验并预览；使用说明对话框说明流程、语法、输出安全、快捷键和常见问题。
- 设置对话框可编辑常用规则、调整界面字号（12–20 px，默认 15）；字体固定为 Microsoft YaHei UI，不提供字体切换。字号通过 QSS 的 px 值整体缩放，窗口布局随之调整。
- 搜索结果底部使用 `ResultStatus` 状态标签，与普通说明文字在底色、边框和字重上区分；状态信息文字保持不变，其他说明压缩为一句，详细内容放在 README 和使用说明中。
- 设置保存在 `%APPDATA%\TXTAdCleaner\settings.ini`（可用 `TXT_AD_CLEAN_SETTINGS_DIR` 覆盖）。
- 提供 `scripts/build_exe.ps1`，用 PyInstaller 生成项目根目录的 `小说广告清理工具.exe`；二进制与 `build/` 不提交仓库。
- 打包时通过 `assets/version_info.txt` 写入 CompanyName、版权、产品名和文件说明（Dayrk0/DSH）；使用 `--runtime-tmpdir "."` 让 onefile 在工作目录解压，避开 `%TEMP%` 权限/安全软件限制导致的 `Could not create temporary directory`。`_MEI*/` 已加入 `.gitignore`。运行时需放在可写目录，不能放 `Program Files` 等只读位置。
- 未做受信任代码签名，首次运行仍可能出现 SmartScreen“未知发布者”提示；版本信息不等于数字签名，彻底消除该提示需要代码签名证书。

## 已知限制

- 只在 Windows 10/11 + Python 3.13.9 + PyQt5 5.15 上验证；macOS/Linux 未测试。
- Big5 与无 BOM 的 UTF-16 识别不可靠，必要时请先转 UTF-8。
- 大文件会占用较多内存（原文、句子列表和匹配结果同时在内存中）；十几 MB 的小说可用，超大文件建议先分段。
- 预览只显示前 200 条命中；完整结果在 `检索结果.txt`。
- `AND` / `OR` 必须大写，关键词区分大小写，不支持正则和通配符。
